[Feedback](/docs/concepts/feedback) is free-text input submitted by end users via the Swift and Android SDKs' `PulseFeedbackView` / `Pulse.sendFeedback` API or the Web and Node SDKs' `Pulse.sendFeedback`. Each submission carries the reporting device (the hardware model on a native app, the browser on web), app version, environment, country, and a session ID linking back to the user's session timeline.
