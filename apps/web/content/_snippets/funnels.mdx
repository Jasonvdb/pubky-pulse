[Funnels](/docs/concepts/funnels) track user progression through a sequence of steps — onboarding, checkout, etc. Definitions are scoped to projects. Each step has a name and an event filter that matches on `step_name` and/or `screen_name`. A `screen_name` filter is an exact match, and on web `screen_name` is the URL path — so a step matches `/checkout`, not `/checkout?cart=9f2` and not `/checkout/payment`.
