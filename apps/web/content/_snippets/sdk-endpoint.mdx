`endpoint` is optional. Leave it out and the SDK falls back to `https://ingest.pubkypulse.com` — [Pubky's own hosted instance](/docs/getting-started/hosted) — and that fallback is silent: nothing is logged, warned, or thrown. So if you run your own Pubky Pulse, you **must** pass your ingest host explicitly; forget it and your data goes to Pubky's instance instead of yours, with nothing to tell you.

The optional `endpoint` needs the SDK releases that ship it. On the currently published `0.1.0` packages `endpoint` is still a required parameter — keep passing it until the release that makes it optional is out.
