## Base URL

Pubky Pulse is self-hosted, so the base URL is your own deployment's API subdomain. Every endpoint lives under the `/v1` prefix. Replace the example hostnames below with your domain:

```
https://api.yourdomain.com/v1
```

SDK event ingestion uses a separate subdomain:

```
https://ingest.yourdomain.com/v1
```

Both subdomains route to the same Fastify server on port 4000. The split exists for operational clarity and independent rate limiting.

## Access model

A deployment has exactly one team, and only email addresses on the configured domains can sign in at all. Within that team:

- **reads are team-wide** — every member reads every project;
- **writes are per project** — ordinary project-scoped mutations require being one of the project's owners, and a `viewer` receives `403`;
- **agent keys inherit their creator's access**, re-read on every request, so an ownership change takes effect on the key's next call;
- **some destructive operations are human-only** — see [Authentication & Access Control](/docs/concepts/authentication).

## Authentication

Pubky Pulse supports two authentication methods:

### JWT Cookie (Dashboard)

Used by the web dashboard. Obtained by verifying an email code via `POST /v1/auth/verify-code`. The server sets an `httpOnly` cookie named `token` with a 10-year `maxAge` — web sessions do not expire.

```
Cookie: token=eyJhbGciOiJIUzI1NiIs...
```

### Bearer Token (API Keys)

Used by SDKs, MCP clients, and programmatic access. Pass the API key in the `Authorization` header:

```
Authorization: Bearer pulse_agent_abc123...
```

There are three key types:

| Type | Prefix | Purpose |
|------|--------|---------|
| Client | `pulse_client_` | SDK event ingestion (scoped to an app) |
| Agent | `pulse_agent_` | MCP and programmatic read/write access; writes follow the key creator's project ownership |
| Import | `pulse_import_` | Bulk historical data import via [`POST /v1/import`](/docs/api-reference/import) (scoped to an app) |

## Error Responses

All error responses follow a consistent format:

```json
{
  "error": "Description of what went wrong"
}
```

Common HTTP status codes:

| Code | Meaning |
|------|---------|
| 400 | Bad request -- missing or invalid parameters |
| 401 | Unauthorized -- missing or invalid credentials |
| 403 | Forbidden -- missing project ownership, key permission, principal type, or recovery authority |
| 404 | Not found -- resource does not exist, is soft-deleted, is outside your team, or does not belong to the parent in the URL |
| 409 | Conflict -- duplicate resource (e.g., slug already exists), or removing the final owner of a project |
| 429 | Rate limited -- too many requests |

## Pagination

List endpoints use cursor-based pagination. Responses include:

```json
{
  "events": [...],
  "cursor": "2024-01-15T10:30:00.000Z",
  "has_more": true
}
```

Pass the `cursor` value as a query parameter to fetch the next page. Default page size is 50, maximum is 200.

| Parameter | Type | Description |
|-----------|------|-------------|
| `limit` | number | Items per page (1-200, default 50) |
| `cursor` | string | Cursor from previous response for next page |

## Rate Limiting

The ingest and events endpoints use an in-memory token bucket rate limiter:

- **100 tokens max** per identity (API key, user, or IP)
- **10 tokens refilled per second**
- One token consumed per request

When the limit is exceeded, the server returns `429 Too Many Requests` with a `Retry-After: 1` header.

## Data Mode

Most read endpoints accept a `data_mode` query parameter to filter development vs. production data:

| Value | Behavior |
|-------|----------|
| `production` | Only production events (default) |
| `development` | Only development events (`is_dev: true`) |
| `all` | Both production and development events |

## MCP endpoint

The same server also hosts the Model Context Protocol endpoint used by AI coding agents: `POST /mcp` (plus `GET /mcp` for the SSE stream; `DELETE /mcp` returns 405). It authenticates with a `pulse_agent_*` Bearer token and exposes 62 tools. See the [MCP docs](/docs/mcp).
