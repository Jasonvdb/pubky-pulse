---
title: Hosted Instance
description: Pubky runs a Pubky Pulse instance for Pubky apps — everyone else self-hosts.
---

Pubky runs its own Pubky Pulse instance at [pulse.pubky.org](https://pulse.pubky.org), used by Pubky's apps. It is not an open sign-up service.

Everyone else runs their own instance. Pubky Pulse is MIT-licensed and self-contained -- a single Fastify API server backed by PostgreSQL -- so a deployment takes well under an hour. See the [Self-Hosting Quickstart](/docs/getting-started/self-hosting).

Nothing else in these docs is specific to either deployment. Wherever an example uses `pulse.pubky.org`, substitute your own instance's hostnames -- the dashboard, the `api.` host for REST and MCP, and the `ingest.` host for SDK configuration.
