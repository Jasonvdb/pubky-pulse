Funnels measure how users progress through a multi-step flow and where they drop off. The SDK side of funnel tracking is a single method call per step. For a broader overview of funnel concepts, analysis modes, and grouping options, see [Funnels](/docs/concepts/funnels).

## Tracking Steps

Call `Pulse.step()` when a user completes a funnel step. The step name you pass must match the `step_name` in your funnel definition's `event_filter`.

```kotlin
Pulse.step("welcome-screen")
Pulse.step("create-account", attributes = mapOf("method" to "email"))
Pulse.step("complete-profile")
Pulse.step("first-post")
```

### Method Signature

```kotlin
public fun step(
    stepName: String,
    attributes: Map<String, String?> = emptyMap(),
)
```

| Parameter | Description |
|-----------|-------------|
| `stepName` | The name of the funnel step. Must match the `step_name` in your funnel definition's `event_filter`. |
| `attributes` | Optional key-value pairs for segmenting funnel analytics later (e.g. signup method, referral source). Values are `String?` — `null`-valued keys are silently dropped, so optional values from your domain code can flow through directly. |

## How It Works

`Pulse.step("welcome-screen")` emits an info-level event with the message `step:welcome-screen` that the server matches against funnel definitions by the step name.

Step names must match exactly between your SDK calls and your funnel definition's `event_filter.step_name` values.

## Example: Onboarding Funnel

Define the funnel on the server with steps that match your `step()` calls:

| Step | Event Filter | SDK Call |
|------|-------------|----------|
| Welcome | `{"step_name": "welcome-screen"}` | `Pulse.step("welcome-screen")` |
| Account Created | `{"step_name": "create-account"}` | `Pulse.step("create-account")` |
| Profile Complete | `{"step_name": "complete-profile"}` | `Pulse.step("complete-profile")` |
| First Post | `{"step_name": "first-post"}` | `Pulse.step("first-post")` |

In your Compose UI:

```kotlin
@Composable
fun WelcomeScreen(onContinue: () -> Unit) {
    Column(modifier = Modifier.pulseScreen("Welcome")) {
        Text("Welcome to the app")
        Button(onClick = {
            Pulse.step("welcome-screen")
            onContinue()
        }) {
            Text("Get Started")
        }
    }
}

suspend fun handleSignup(email: String, password: String) {
    try {
        createAccount(email, password)
        Pulse.step("create-account", attributes = mapOf("method" to "email"))
    } catch (e: Throwable) {
        Pulse.error(e, "Signup failed", screenName = "Signup")
    }
}
```

## Funnel Definitions

Funnel definitions are created through the dashboard or the `create-funnel` MCP tool, not through the SDK. The SDK only emits the step events. Define matching definitions first:

```json
{
  "project_id": "<id>",
  "name": "Onboarding",
  "slug": "onboarding",
  "steps": [
    {"name": "Welcome", "event_filter": {"step_name": "welcome-screen"}},
    {"name": "Account", "event_filter": {"step_name": "create-account"}},
    {"name": "Profile", "event_filter": {"step_name": "complete-profile"}},
    {"name": "First Post", "event_filter": {"step_name": "first-post"}}
  ]
}
```

See [Funnels](/docs/concepts/funnels) for details on creating definitions, analysis modes (open vs closed), and query options.
