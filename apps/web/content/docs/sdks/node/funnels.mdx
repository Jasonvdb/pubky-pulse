Use `Pulse.step()` to emit named step completions that feed into [funnel analytics](/docs/concepts/funnels). The step name you pass must match the `step_name` in your funnel definition's `event_filter`.

## Tracking Steps

```typescript
Pulse.step("signup-started");
Pulse.step("email-verified");
Pulse.step("profile-completed");
```

You can include optional attributes:

```typescript
Pulse.step("plan-selected", { plan: "pro", interval: "annual" });
```

## Per-User Funnel Tracking

Funnels are most useful when steps are associated with a specific user. Use a scoped instance so every step carries the user ID:

```typescript
const pulse = Pulse.withUser(userId);
pulse.step("checkout-started");
// ... later
pulse.step("payment-completed");
pulse.step("order-confirmed");
```

Without a user ID, funnel analytics cannot correlate steps across a conversion path.

## Backend Funnel Patterns

Backend services often track steps that happen outside the client -- webhook callbacks, background jobs, or server-side validation. These complement client-side funnel tracking by capturing the full picture.

### Webhook-Driven Steps

```typescript
app.post("/webhooks/stripe", async (req, res) => {
  const event = req.body;
  const pulse = Pulse.withUser(event.data.object.metadata.user_id);

  if (event.type === "payment_intent.succeeded") {
    pulse.step("payment-succeeded", { amount: String(event.data.object.amount) });
  }

  if (event.type === "invoice.paid") {
    pulse.step("subscription-activated");
  }

  res.sendStatus(200);
});
```

### Background Job Steps

```typescript
async function processOnboarding(userId: string) {
  const pulse = Pulse.withUser(userId);

  await generateWelcomeEmail(userId);
  pulse.step("welcome-email-sent");

  await provisionAccount(userId);
  pulse.step("account-provisioned");
}
```

## Defining Funnels

Funnel steps recorded by the SDK are matched against funnel definitions on the server. Define your funnels in the dashboard or with the `create-funnel` MCP tool, using the step names you pass to `step()`. Each step's `event_filter.step_name` should match the string you pass to `step()`.

See [Funnels](/docs/concepts/funnels) for details on how funnel definitions, analytics, and query modes work.
