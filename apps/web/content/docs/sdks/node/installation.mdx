Install the `@synonymdev/pubky-pulse-node` package from npm.

## Install

```bash tab="npm"
npm install @synonymdev/pubky-pulse-node
```

```bash tab="pnpm"
pnpm add @synonymdev/pubky-pulse-node
```

```bash tab="yarn"
yarn add @synonymdev/pubky-pulse-node
```

## Import

The SDK ships both ESM and CommonJS builds. Import it in your application entry point:

```typescript tab="ESM"
import { Pulse } from "@synonymdev/pubky-pulse-node";
```

```javascript tab="CommonJS"
const { Pulse } = require("@synonymdev/pubky-pulse-node");
```

## Zero Dependencies

`@synonymdev/pubky-pulse-node` has no runtime dependencies. It uses only Node.js built-in modules (`node:crypto`, `node:zlib`, `node:fs`, `node:os`, `node:path`) and the global `fetch` API available in Node.js 20+.

## Requirements

- **Node.js 20+** -- required for native `fetch` and `AbortSignal.timeout` support
- **ESM or CommonJS** -- the package exports both via conditional `exports` in `package.json`

## Next Steps

Once installed, [configure the SDK](/docs/sdks/node/configuration) with your API key and endpoint.
